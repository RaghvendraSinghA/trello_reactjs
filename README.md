# Trello Clone

A Trello Clone built using React and Node.js, with real-time synchronization using Trello Webhooks and WebSockets.

## Prerequisites

Make sure you have installed:

- Node.js and npm
- Ngrok
- Git

## Project Setup

Clone the repository:

```bash
git clone <your-repository-url>
cd <project-root-folder>
```

## 1. Start Ngrok (First)

Open a terminal and run:

```bash
ngrok http 3000
```

Ngrok exposes your local backend server to the internet so Trello can send webhook events to it.

Copy the HTTPS forwarding URL generated by Ngrok.

Example:

```text
https://your-ngrok-domain.ngrok-free.dev
```

**Important:** Make sure the webhook callback URL in your backend/Trello webhook configuration uses this Ngrok URL:

```text
https://your-ngrok-domain.ngrok-free.dev/trello-webhook
```

Keep Ngrok running.

## 2. Start Backend

Open a new terminal and navigate to the backend directory:

```bash
cd backend
```

Install dependencies:

```bash
npm install
```

Start the backend server:

```bash
npm start
```

The backend runs on:

```text
http://localhost:3000
```

The backend handles:
- Trello webhook events.
- WebSocket connections.
- Broadcasting real-time updates to connected frontend clients.

Keep the backend running.

## 3. Start Frontend

Open another terminal and navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the React development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal (usually `http://localhost:5173`).

## Startup Order

Every time you start the project, follow this order:

1. **Ngrok:** Run `ngrok http 3000`.
2. **Backend:** Run `npm install` (first time or when dependencies change), then `npm start`.
3. **Frontend:** Run `npm install` (first time or when dependencies change), then `npm run dev`.

## Important Notes

- Keep all three processes running while using the application.
- Ngrok must be running for Trello to send webhook events to your local backend.
- The frontend connects to the backend using WebSockets at `ws://localhost:3000`.
- If your Ngrok URL changes, update the registered Trello webhook callback URL accordingly.
- Do not commit `.env` files or expose your Trello API credentials.
